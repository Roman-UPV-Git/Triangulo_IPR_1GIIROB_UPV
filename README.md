# Triangulo_IPR_1GIIROB_UPV
Mi resolución de la tarea del triángulo puesta por Miguel Rebollo.

triangulo.c : File que contiene el código funte en C.
  - Contiene comentarios de todas las partes del código (estructuras, funciones, partes del código principal...)
  - Se ha priorizado la legibilidad frente a la brevedad de líneas.

triangulos.txt : File de texto que contiene los casos de triángulos pedidos por Rebollo
  - Para usar automaticamente en triangulo.c: 
      Cread el ejecutable del código (gcc triangulo.c -o triangulo.exe -lm -Wall) sin olvidarse del '-lm' para la biblioteca 'math.h'
      Ejecutad el ejecutable de la siguiente forma: triangulo.exe < triangulos.txt (O el nombre que le hayáis dado al ejecutable)
